# Чат-бот «Транспорт Великого Новгорода» (MAX Messenger)

Официальный чат-бот для мессенджера **MAX** (`@cds_ot_vn_bot` — «Транспорт Великого Новгорода»), предоставляющий пассажирам актуальную информацию о городском общественном транспорте: расписание движения автобусов и троллейбусов, инструкции по безналичной оплате и покупке билетов, пополнению карт «Береста», тарифам, контактам перевозчиков и пунктам обслуживания.

## 1. Архитектура и схема работы

Бот работает по схеме **Webhook**: сообщения от пользователей приходят на сервер через обратный вызов (push) от платформы MAX.

```
Пользователь (клиент MAX)
       │
       ▼
Платформа MAX (https://platform-api2.max.ru)
       │  POST https://bot-api.transport.nov.ru/webhook
       │  Заголовок: X-Max-Bot-Api-Secret: <SECRET>
       ▼
Веб-сервер Apache (HTTPS / порт 443)
       │  Терминация SSL Let's Encrypt
       │  ProxyPass /webhook -> http://127.0.0.1:8081/webhook
       ▼
Python-сервис bot.py (порт 127.0.0.1:8081)
       │
       ├─► Проверка секрета X-Max-Bot-Api-Secret
       ├─► Парсинг событий (message_created, message_callback, bot_started)
       ├─► Обращение к БД MySQL (transport_rcit) через timetable_service.py
       │
       ▼
Ответ в платформу MAX (REST API)
       ├─► POST /messages?user_id=... (ответ на текстовое сообщение)
       └─► POST /answers?callback_id=... (обновление сообщения по кнопке)
```

Также веб-сервер Apache напрямую отдает статические файлы (памятки, PDF-документы) из каталога `/var/www/bot-api/media/` по протоколу HTTPS.

## 3. Функционал чат-бота

### 3.1. Главное меню и приветствие

При старте бота (`/start`, событие `bot_started` или нажатие кнопки «🏠 Главное меню») бот отправляет приветственное сообщение и интерактивную inline-клавиатуру из 7 пунктов:

> **Здравствуйте!**  
> Рады приветствовать Вас в чат - бот «Транспорт Великого Новгорода».  
> Я Ваш виртуальный помощник по городскому общественному транспорту.

Кнопки меню:
1. `Расписание движения городских маршрутов` (payload: `ask_route`)
2. `Как приобрести билет посредством чат-бота` (payload: `how_to_buy`)
3. `Как пополнить проездные билеты в мобильном приложении «Транспортная карта»` (payload: `how_to_topup`)
4. `Узнать стоимость проезда` (payload: `fares`)
5. `Узнать виды проездных билетов и их стоимость` (payload: `ticket_types`)
6. `Перевозчики` (payload: `carriers`)
7. `Полезная информация` (payload: `useful_info`)

---

### 3.2. Поиск расписания маршрутов

При выборе пункта «Расписание движения городских маршрутов» бот предлагает ввести номер маршрута:
> 🚌 Введите номер интересующего маршрута в чат  
> (например: 1, 4, 11, 101 или троллейбус 2):

#### Алгоритм работы поисковика (`search_routes` в `bot.py`):
1. **Нормализация текста**: строка переводится в нижний регистр, очищаются пробелы.
2. **Определение типа транспорта**:
   - Слова `троллейбус`, `тролейбус`, отдельная буква `т` указывают на фильтрацию только троллейбусов (`vehicle = 2`).
   - Слова `автобус`, отдельная буква `а` указывают на автобусы (`vehicle = 1`).
   - Если ключевых слов нет — поиск выполняется по обоим видам транспорта.
3. **Извлечение номера**: регулярное выражение `([0-9]+[а-яa-z]*)` находит числовую часть вместе с возможным буквенным индексом (например: `1`, `1а`, `2к`, `101`).
4. **Запрос к БД**: берутся только активные маршруты (`visibility = 1`). Поддерживается сопоставление как точного номера, так и составных номеров через запятую (например, `4, 20`).
5. **Варианты ответа**:
   - **Найден ровно 1 маршрут**: бот отправляет карточку маршрута с конечными остановками и кнопкой-ссылкой `🌐 Открыть расписание на сайте`, ведущей на `https://transport.nov.ru/timetable/table.html?route=<id>`.
   - **Найдено несколько маршрутов** (например, пользователь ввел «2», и есть автобус №2 и троллейбус №2): бот отображает меню выбора с отдельной кнопкой на каждый найденный маршрут.
   - **Ничего не найдено**: бот выводит сообщение `Маршрут «...» не найден` с рекомендацией проверить номер и кнопкой возврата в меню.

### 3.3. Разделы информации и билетов

- **Как приобрести билет посредством чат-бота**: подробная 4-шаговая инструкция (авторизация с кликабельной ссылкой на официальный билетный бот `https://max.ru/id5406119655_1_bot`, поиск QR-кода в салоне, подтверждение списания, контроль поездки и правила предъявления электронного билета).
- **Как пополнить проездные билеты**: текстовое пояснение и кнопка `🖼 Открыть памятку (изображение)`, открывающая `https://bot-api.transport.nov.ru/media/popolnenie.png`.
- **Узнать стоимость проезда**: актуальная тарифная сетка (43 рубля при оплате картой «Береста», 45 рублей при иных способах оплаты).
- **Узнать виды проездных билетов и их стоимость**: пояснение и кнопка `📄 Скачать документ (PDF)`, открывающая официальный документ `https://bot-api.transport.nov.ru/media/vidy_proedzdnih.pdf`.
- **Перевозчики**: полная информация по обслуживаемым маршрутам, адресам, диспетчерским службам, приёмным и электронной почте предприятий:
  - АО «Автобусный парк»
  - ООО «Городское пассажирское автотранспортное предприятие» (ООО «Городское ПАТП»)
- **Полезная информация**: подменю с двумя подразделами:
  - *Основные точки по продаже проездных билетов*: 4 пункта продаж (ул. Фёдоровский ручей, ул. Свободы, ул. Хутынская, ул. Нехинская) с подробным расписанием работы по дням месяца, обеденными перерывами и техническими перерывами.
  - *Претензионный центр по вопросам, касающимся электронной оплаты проезда*: адрес бухгалтерии ООО «ЦДС ОТ» (ул. Германа, д. 39), режим работы, обеденный перерыв и контактный телефон 8 (8162) 777-850.
  - Кнопки навигации: `◀ Назад` и `🏠 Главное меню`.

## 4. Особенности API платформы MAX

1. **Inline-клавиатуры (`inline_keyboard`)**:
   - **Ограничение на ширину строки (`errors.maxRowSize`)**: платформа MAX отклоняет запросы с ошибкой HTTP 400, если в одной строке клавиатуры расположено **более 3 кнопок**.
   - Для стабильного отображения длинных названий на экранах смартфонов в боте используется компоновка **по 1 кнопке в строке**.
2. **Типы кнопок**:
   - `callback`: возвращает событие `message_callback` с полем `payload`. Обрабатывается через метод API `/answers?callback_id=...`, что позволяет редактировать сообщение на месте без спама новыми сообщениями.
   - `link`: открывает внешнюю ссылку прямо в браузере или приложении (используется для расписания на сайте, перехода в билетный бот, просмотра картинок и PDF).
3. **Верификация вебхука**:
   - Платформа MAX передает в каждом POST-запросе HTTP-заголовок `X-Max-Bot-Api-Secret`.
   - Если заголовок не совпадает со значением переменной окружения `MAX_WEBHOOK_SECRET`, сервер возвращает `403 Forbidden` и запрос отбрасывается.

## 5. Взаимодействие с базой данных

Бот подключается к базе данных сайта `transport.nov.ru` — MySQL `transport_rcit`.

Основные таблицы:
- **`timetable_routes`**: справочник маршрутов
  - `id` (int): уникальный ID маршрута на сайте;
  - `number` (varchar): номер маршрута (например, `4`, `1а`, `11`, `53Т`);
  - `point1`, `point2` (varchar): начальная и конечная остановки;
  - `vehicle` (tinyint): `1` — автобус, `2` — троллейбус;
  - `visibility` (tinyint): `1` — активен (отображается на сайте), `0` — скрыт/архив;
  - `num` (int): порядковый номер для правильной сортировки в списках.
- **`timetable_tables`**: HTML-таблицы расписаний по каждому направлению маршрута.
- **`timetable_groupes`**: группировка расписаний по дням («По рабочим дням», «По выходным дням»).

Модуль `timetable_service.py` также содержит потокобезопасный парсер `TableHTMLParser`, позволяющий разбирать остановки и времена рейсов из HTML-кода таблиц с встроенным TTL-кэшированием на 1 час.

Параметры подключения к MySQL берутся из переменных окружения (с дефолтными значениями для сервера):
- `DB_HOST` (по умолчанию: `localhost`)
- `DB_USER` (по умолчанию: `transport_nov_ru`)
- `DB_PASSWORD` (по умолчанию: `De^h78ytqL`)
- `DB_NAME` (по умолчанию: `transport_rcit`)

## 6. Установка и развертывание на сервере

### 6.1. Системные требования

- ОС: Debian 10 / 11 / 12 или Ubuntu 20.04 / 22.04 / 24.04 LTS
- Python: 3.7+
- Веб-сервер: Apache 2.4 с модулями `proxy`, `proxy_http`, `ssl`
- СУБД: MariaDB / MySQL 5.7+
- Зависимости Python: `pymysql`

Установка системных зависимостей (Debian/Ubuntu):
```bash
sudo apt update
sudo apt install -y python3 python3-pip apache2
sudo pip3 install pymysql
sudo a2enmod proxy proxy_http ssl rewrite
```

---

### 6.2. Размещение файлов и права доступа

На рабочем сервере файлы распределены следующим образом:

| Путь на сервере | Описание | Владелец / Права |
|-----------------|----------|------------------|
| `/opt/max-bot/bot.py` | Исполняемый файл бота | `cds:cds`, `755` |
| `/opt/max-bot/timetable_service.py` | Модуль работы с БД | `cds:cds`, `644` |
| `/opt/max-bot/webhook.env` | Секрет вебхука | `root:root`, `600` |
| `/etc/max-bot.env` | Токен API бота | `root:root`, `600` |
| `/var/www/bot-api/media/` | Каталог медиафайлов | `cds:www-data`, `775` |
| `/etc/systemd/system/max-bot.service` | Сервис systemd | `root:root`, `644` |
| `/etc/apache2/sites-available/bot-api.transport.nov.ru.conf` | Конфигурация Apache | `root:root`, `644` |

---

### 6.4. Настройка веб-сервера Apache

Скопируйте `apache/bot-api.transport.nov.ru.conf` в `/etc/apache2/sites-available/bot-api.transport.nov.ru.conf`, включите сайт и перезапустите Apache:

```bash
sudo a2ensite bot-api.transport.nov.ru.conf
sudo systemctl reload apache2
```

Проверка доступности медиафайлов:
```bash
curl -sI https://bot-api.transport.nov.ru/media/popolnenie.png
curl -sI https://bot-api.transport.nov.ru/media/vidy_proedzdnih.pdf
```
Должен возвращаться код ответа `HTTP/1.1 200 OK`.

---

### 6.5. Настройка службы systemd

Скопируйте `systemd/max-bot.service` в `/etc/systemd/system/`:

```bash
sudo cp systemd/max-bot.service /etc/systemd/system/max-bot.service
sudo systemctl daemon-reload
sudo systemctl enable max-bot.service
sudo systemctl restart max-bot.service
```

Проверка статуса службы:
```bash
sudo systemctl status max-bot.service
```

## 7. Утилиты и диагностика

В каталоге `tools/` находятся готовые скрипты:

1. **Проверка авторизации бота в MAX**:
   ```bash
   python3 tools/get_me.py
   ```
   Выводит JSON с ID бота, именем («Транспорт Великого Новгорода»), юзернеймом (`cds_ot_vn_bot`) и описанием.

2. **Тестирование алгоритма поиска маршрутов**:
   ```bash
   python3 tools/test_search.py 1 4 11 101 "троллейбус 2" "1а"
   ```
   Показывает, как алгоритм парсит входящие запросы и какие маршруты из БД сопоставляет.
